# Android RecyclerView Example

Sebuah proyek aplikasi Android sederhana untuk mendemonstrasikan penggunaan RecyclerView dengan menggunakan ConstraintLayout.

📱 Tentang Proyek

Aplikasi ini adalah contoh dasar bagaimana cara mengimplementasikan dan menampilkan daftar (list) data secara efisien di Android menggunakan RecyclerView. Tata letak utama didefinisikan dalam activity_main.xml dan menggunakan card_view_design.xml sebagai desain untuk masing-masing item di dalam daftar.

✨ Fitur

Menampilkan daftar item menggunakan RecyclerView.

Menggunakan ConstraintLayout untuk tata letak utama yang responsif.

Kustomisasi desain item menggunakan CardView (rujukan ke @layout/card_view_design).

🛠️ Teknologi yang Digunakan

Bahasa: Kotlin 

UI Layout: XML (ConstraintLayout, RecyclerView)

IDE: Android Studio

🚀 Cara Menjalankan Proyek

Clone repository ini ke komputer lokal Anda:

git clone https://github.com/anggraenisilvi413-sudo/RecyclerViewSample.git


Buka Android Studio.

Pilih Open an existing project dan arahkan ke folder hasil clone.

Tunggu proses Gradle sync selesai.

Jalankan aplikasi di Emulator atau perangkat Android fisik Anda dengan menekan tombol Run (Shift + F10).
